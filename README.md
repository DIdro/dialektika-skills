# Скиллы ГК Диалектика для Claude Code

Маркетплейс плагинов с методическими скиллами. Ставится в Claude Code одной командой, обновляется из этого репозитория.

## Установка

В Claude Code выполните три команды:

```
/plugin marketplace add DIdro/dialektika-skills
/plugin install sdm@dialektika
/plugin install voice@dialektika
/reload-plugins
```

Первая команда добавляет каталог, вторая ставит плагин (откроется окно выбора области установки — подтвердите), третья активирует его в текущей сессии.

## Что доступно

| Плагин | Вызов | Что делает |
| --- | --- | --- |
| `sdm` | `/sdm` | Строит образ бренда, продукта, услуги или выступления по методу семиотического дискурсивного моделирования (Г. Н. Лола). Подробности — [plugins/sdm/README.md](plugins/sdm/README.md) |
| `voice` | `/voice` | Пишет и правит тексты вашим голосом. Голос не описывается словами, а измеряется по корпусу ваших опубликованных текстов. Три режима: чистка чужого текста от следов ИИ, письмо из заметок, длинная форма. Подробности — [plugins/voice/README.md](plugins/voice/README.md) |

Скилл срабатывает и сам, когда вы просите «сделать образ», найти метафору или концепцию бренда — вызывать `/sdm` руками не обязательно.

## Обновления

```
/plugin marketplace update dialektika
```

Версии плагинов и что в них менялось — в [CHANGELOG.md](CHANGELOG.md).

## Требования

Claude Code (CLI, десктоп или IDE-расширение). Скилл работает на любой модели, но метод требовательный к рассуждению — на Opus качество прогона заметно выше.

Для Claude в вебе (claude.ai) плагины не поддерживаются: там скилл ставится zip-архивом папки нужного скилла (`plugins/sdm/skills/sdm/`, `plugins/voice/skills/voice/`) через Настройки → Функции, отдельно для каждого пользователя.

## Об использовании

Метод СДМ — авторская разработка Г. Н. Лола («Дизайн-код»). Этот репозиторий содержит рабочий дистиллят метода в виде инструкции для агента, подготовленный ГК Диалектика.

Скиллы передаются клиентам и партнёрам ГК Диалектика для использования в собственной практике. Перепубликация, продажа и включение в состав коммерческих продуктов — по согласованию: gmdidro@gmail.com

## Безопасность

Скиллы исполняются с правами вашего пользователя. Ставьте их только из источников, которым доверяете, и просматривайте содержимое перед установкой — здесь это два markdown-файла без скриптов и сетевых вызовов.
