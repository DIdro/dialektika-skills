# speaker-venues — подбор площадок под портрет спикера

Скилл делает работу спикер-менеджера по поиску площадок: по портрету одного
спикера находит, **куда его подать сейчас** и **с кем знакомиться впрок**.

## Что на выходе

Таблица (xlsx + md) из трёх листов:

- **Подать сейчас** — мероприятия в заданном горизонте: даты, аудитория,
  секция под тему спикера, срок приёма заявок, как подать, условия для
  спикера (бесплатно / платно / не указано), оценка 1–3 и почему подходит.
- **Знакомиться впрок** — площадки без текущего анонса: ежегодные конференции
  с закрытым приёмом, сообщества, клубы, медиа, подкасты. С маршрутом входа
  и ожидаемым окном подачи следующего выпуска.
- **Отброшено** — что проверено и почему не подошло, чтобы не проверять
  повторно.

У каждой строки есть ссылка-доказательство. Даты, контакты и условия берутся
только со страницы источника: чего нет на странице, того нет в таблице.

## Как работает

1. Портрет спикера из базы спикеров (или по медиакиту) — темы на языке
   программ конференций, аудитория, форматы, география.
2. Поиск по российским агрегаторам (All-events, ICT2Go, Expomap), сайтам
   организаторов деловых конференций, Telegram-каналам анонсов и веб-поиску
   по формулировкам приёма заявок.
3. Проверка каждой находки по официальному сайту события.
4. Сверка с базой площадок: новые / уже в базе, но с новым поводом.

Источники и что из них реально работает — в
[`skills/speaker-venues/references/sources.md`](skills/speaker-venues/references/sources.md).

## Базы

Базы спикеров и площадок — Google-таблицы, скилл читает их тем доступом к
Google, который настроен у вас (например, сервисный аккаунт). Схема столбцов
свободная. Без баз скилл тоже работает — портрет по медиакиту, без сверки.

Настройки — в файле `speaker-venues.config.md` в корне рабочей папки; шаблон
в разделе «Конфиг» [SKILL.md](skills/speaker-venues/SKILL.md).

## Чего скилл не делает

Не пишет организаторам, не заполняет формы заявок и не меняет строки в
базах. Дописать находки в базу площадок предлагает только отдельным листом и
только после вашего подтверждения.

## Вызов

```
/speaker-venues <имя спикера>
```

или просто: «подбери площадки для <имени> до конца года».

Один прогон — порядка 25 поисков и 50 открытых страниц, 30–40 минут.
