# Источники площадок

Проверено 29.09.2026 (ресёрч готовых решений + тестовый прогон на одном спикере).

Готового сервиса подбора площадок под российского спикера нет: западные
CFP-платформы (Sessionize, PaperCall, confs.tech, SpeakingGig, SpeakerAgent)
почти не покрывают РФ, российские спикерские агентства (HubSpeakers,
TopSpeaker, «Ваш Спикер») работают вручную и API не дают. Готовые агентные
скиллы и MCP под поиск CFP есть (Microsoft CAT Agent Skills — дайджест CFP,
jbaruch/nanoclaw-conferences, call-for-papers-mcp, Apify Conference CFP Finder),
но все стоят на западных CFP-фидах (Sessionize, PaperCall, confs.tech, WikiCFP)
и dev/академических темах. Российский приём заявок живёт на сайтах
организаторов и агрегаторах, поэтому скилл сам обходит агрегаторы, сайты
организаторов, каналы и веб-поиск.

Порядок обхода: агрегаторы (All-events → Timepad API, если есть токен → ICT2Go → Expomap) → точечные
запросы «конференция <роль аудитории> 2026» → сайты организаторов →
Telegram → медиа и подкасты. Резерв — в конце файла.

## 1. Агрегаторы мероприятий

| Источник | Что там | Как опрашивать |
|---|---|---|
| **All-events** — лучший в тесте | Деловые события по городам и тегам; карточка даёт организатора, цену, аудиторию | WebFetch календаря по шаблону `all-events.ru/events/calendar/city-is-<город>/tags-is-<тег>/` или `.../theme-is-<тема>/`. Рабочие примеры: `city-is-moskva/tags-is-iskusstvennyi_intellekt/`, `city-is-moskva/tags-is-tcifrovaia_transformatciia/`, `city-is-moskva/theme-is-ai/`. Условий для спикеров в карточке нет — идти на официальный сайт |
| **ICT2Go** | IT, digital, ИИ | WebFetch `ict2go.ru/events/`, `ict2go.ru/themes/ai/`, `ict2go.ru/regions/<город>/`. Карточка `/events/<id>/` — источник ссылки на официальный сайт. Отметки «Приём заявок» пересказчик извлекает ненадёжно |
| **Expomap** | Деловые конференции и выставки по темам и тегам | WebFetch `expomap.ru/conference/theme/<слаг>/2026/` или `.../tag/<слаг>/2026/`. Рабочие слаги: `theme/menedzhment-hr`, `tag/change-management`. ⚠️ Неверный слаг даёт «Найдено 0 событий», а не ошибку — не делать из этого вывод «событий нет». WebFetch видит только первую страницу пагинации |
| **Timepad API** — только с токеном | Самая широкая база РФ: ~12 тыс. будущих событий в Москве. Хорошо ловит средние деловые события, отраслевые ассоциации, сообщества предпринимателей и организаторов, которые зовут экспертов на мастер-классы — сырьё для «впрок». Приёма заявок спикеров не показывает | См. «Timepad: рецепт» ниже |
| **cisoclub.ru** | Вторичный агрегатор карточек событий с организатором и треками | Веб-поиск `site:cisoclub.ru <тема> конференция 2026` |

### Timepad: рецепт

Токен — бесплатно на `dev.timepad.ru/api/oauth/` под своим аккаунтом Timepad
(вход по телефону). Отметить **только** «Просматривать публичные события
(view_events)»: токен наследует права пользователя, лишние права не нужны.
Хранить вне рабочей папки (например, `~/.secrets/timepad.env`,
`TIMEPAD_TOKEN=…`), в конфиге указать путь к файлу, а не сам токен.

Запрос (curl или Python; ⚠️ Python-urllib с дефолтным User-Agent получает
403 — ставить заголовок `User-Agent`):

```
GET https://api.timepad.ru/v1/events
  ?keywords=<тема>&cities=Москва&category_ids=217,452
  &starts_at_min=<сегодня>&starts_at_max=<конец горизонта>
  &sort=+starts_at&limit=50&fields=location,organization
Authorization: Bearer <TIMEPAD_TOKEN>
```

Категории: 217 Бизнес, 452 ИТ и интернет, 453 Психология и самопознание,
2465 Наука (полный список — `/v1/dictionary/event_categories`). Без
`starts_at_min` и `sort` сверху идут «вечные» события с датами 2045–2050.
Ключевые слова ищутся в основном по названию — давать 3–5 коротких вариантов
(«конференция», «форум», «личный бренд», «нейросети»), а не фразу из портрета.
Названия приходят с HTML-сущностями (`&quot;`) — декодировать.

Проверено 29.09.2026: `конференция` + Москва + Бизнес → 31 событие на
окт–дек; `форум` → 39; `личный бренд` → 8 (мастер-классы и секции на
отраслевых форумах).

## 2. Точечные запросы под аудиторию спикера

В тесте дали самые ценные строки — сильнее агрегаторов. Строить от роли
аудитории, а не от темы спикера:

- `конференция <роль аудитории> 2026` — например «операционный директор COO»,
  «финансовый директор», «HR-директор», «собственник бизнеса»
- `форум <отрасль / функция> 2026 программа спикеры`
- `"приём заявок спикеров" <тема> 2026`
- `"стать спикером" <тема> конференция`
- `"подать доклад" OR "call for speakers" <тема> 2026`
- `"программный комитет" <тема> конференция 2026`
- `site:habr.com "приём заявок на доклады"` — технические и продуктовые темы

## 3. Организаторы деловых конференций с формой для спикеров

Регулярные организаторы — кандидаты и в «Подать сейчас», и в «Знакомиться
впрок». Открывать их страницы событий и спикерские формы:

| Организатор | Где | Профиль |
|---|---|---|
| CFO Russia | `cfo-russia.ru/meropriyatiya/bespeaker/` — общая форма спикера | Финансы, управление |
| Открытые системы | `osp.ru/events`, conf@osp.ru | ИТ для бизнеса, ИИ |
| CNews Conferences | `cnconf.ru` | ИТ для бизнеса, цифровизация |
| TAdviser | `tadvisersummit.ru` | ИТ-директора, цифровизация |
| Интер Форум | `interforums.ru`, info@interforums.ru | Операционные директора, управление |
| Quorum | `quorumconference.ru` | HR Tech, ИИ-трансформация |
| LBS / HR Summit | `hrsummit.ru`, info@hrsummit.ru | HR, корпоративное обучение |
| B-FORUMS | `globaltechforum.ru` | Технологии для бизнеса; часто спонсорские пакеты |
| Коммерсантъ Конференции | `events.kommersant.ru` | Отраслевые деловые конференции |
| Онтико | speakers@ontico.ru | Технические конференции (HighLoad и др.) |

Список расширять под нишу каждого спикера и записывать удачных организаторов
в конфиг («Доп. источники команды»).

## 4. Telegram (веб-превью без логина)

WebFetch `https://t.me/s/<канал>` — последние ~20 постов.

| Канал | Результат теста |
|---|---|
| `@event_live_ru` | ✓ дал событие, которого не было на агрегаторах |
| `@kommersantevents` | ◐ вывел на организатора |
| `@iteventsru` | ◐ IT, в основном мимо деловых тем |
| `@allbusinessevents` | ✗ в основном юридические анонсы |
| `@expopeople` | не проверен |

Отраслевые каналы ниши спикера найти запросом
`telegram канал анонсы мероприятий <отрасль>`.

«Спикеры России» — закрытый платный канал с запросами организаторов на спикеров
(72–180 тыс. ₽/год), API нет. Если команда купит доступ — пересылать посты
в папку `входящие/` и отдавать скиллу как источник.

## 5. Медиа и подкасты (для «Знакомиться впрок»)

В тесте общие подборки подкастов не дали ни одной площадки с проверяемым
составом гостей. Искать выпуски, а не подборки:

- `site:mave.digital <тема>` / `site:podcast.ru <тема>`
- `подкаст гость "<роль похожего спикера>" <тема> выпуск 2026`
- `интервью <тема> <роль> youtube 2026` — YouTube-каналы бизнес-медиа
- Telegram-каналы с регулярными эфирами по теме спикера

Брать только площадку, где на странице видны прошлые гости уровня спикера.

## 6. Резерв (в тесте дали 0 строк)

- Timepad без токена (`site:timepad.ru`) — старые события 2019–2024. Если
  токена нет — лучше попросить завести (раздел 1, «Timepad: рецепт»).
- Росконгресс (`site:roscongress.org`) — выдаёт статьи, а не события.
- Leader-ID (`site:leader-id.ru`) — в основном прошедшие события.
- Sessionize (`site:sessionize.com <тема> 2026`) — редкие русскоязычные события.

## 7. Что WebFetch не читает

Данные подгружаются JS или сайт отдаёт ошибку: `kazandigitalweek.com`,
`ontico.ru/calendar.html`, `hrevent.talentrocks.ru` (только описание),
`rbc.ru/businessclass/` (401), `tok.tochka.com` (ошибка сертификата).
Для них — поиск по новостям о событии или браузер (Playwright), если он
подключён.

## Цикл площадки: следующее окно подачи

Крупные конференции закрывают приём заявок за 3–6 месяцев до события
(осенние — летом), а в тесте срок подачи был указан только у 1 события из 13.
Поэтому ежегодная конференция с закрытым приёмом — не отказ, а строка в
«Знакомиться впрок»: месяц прошлого выпуска и ожидаемое окно подачи
следующего («прошлый — ноябрь 2025, заявки были до июля → писать в
программный комитет в апреле–мае 2026»).
