# СДМ — playbook (дистиллят метода Г.Н.Лола «Дизайн-код»)

## 4 этапа (порядок строгий)

### 1. К — Конструирование концепта
- I. Форматирование инф. ситуации: цель / целевые аудитории / компетенции бренда / позиционирование.
- II. Развёртывание плана имманенции: портрет Другого / компетенции дизайн-продукта.
- III. Формулирование концепта.

### 2. СМ — Семиотическое моделирование
Стягивание семиотических ресурсов → коннотативные ряды (образный + абстрактный) → ключевые коннотации → метафора → тема → базовый нарратив («образ для себя»).

### 3. ДМ — Дискурсивное моделирование
Перемещение на периферию образа → направляющие коды (фрейминг: синхронизация/умножение; рефрейминг: смещение/подмена; трансфрейминг: диссоциация) → контекстуализация → метанарратив («образ для Другого»; после написания «забыть»).

### 4. КА — Культурная анимация
Легенда (синтагматический / парадигматический / индексический контексты; история / инспирации / метафизические реминисценции) → сценарий перфоманса (валоризация: историзация / персонификация / артизация / драматизация / «эстетизация убожества»).

## Типология «Другого» (8 типов)
- Простой потребитель: имитатор, неофит, функционалист, традиционалист.
- Сложный потребитель: экспериментатор, индивидуалист, нарцисс, эстет.

## Антипаттерны (ловушки — сверяться)
- Концепт ≠ цель и ≠ позиционирование (концепт чувствен, выразителен, зрим).
- ЦА ≠ портрет Другого (ЦА — социодемография; портрет — конкретный собирательный человек).
- Компетенции продукта ≠ инструменты («богата тактильностью», не «использование разной бумаги»).
- Не повторять метафору в теме.
- Не выводить коды из коннотаций (коды *преодолевают* семиотическое ядро, а не зеркалят).
- Направляющие коды звучат как глаголы.
- Метанарратив — «для Другого», сразу «забыть».
- Культурная анимация ≠ реклама.

## Форма результата — BrandImage
```yaml
brand_image:
  object: ""              # что за сущность (бренд/продукт/методология/презентация)
  other_portrait: ""      # портрет Другого (собирательный человек, НЕ соцдем)
  other_type: ""          # один из 8 типов типологии
  concept: ""             # чувственный, зримый — НЕ позиционирование
  key_connotations: []    # ключевые коннотации
  metaphor: ""
  theme: ""               # НЕ повторяет метафору
  base_narrative: ""      # образ для себя
  guiding_codes: []       # глаголы; преодолевают ядро
  visual_language: ""     # что это даёт дизайну: типографика/цвет/композиция
  tone: ""
  taboo: []               # чего образ не делает
```
Поля `visual_language`, `tone`, `taboo`, `metaphor` и `theme` — прямой вход для вёрстки и копирайтинга: с них начинается работа над сайтом, презентацией или айдентикой.
